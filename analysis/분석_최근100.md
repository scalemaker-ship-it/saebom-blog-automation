## 2. A 그룹 고정 순서 (템플릿)

1. 제목 반복(본문 첫 줄, 2줄) → 대표 이미지(원장 실사)
2. 인사 「안녕하세요. / 광주 새봄의원입니다.」
3. 공감 도입: 독자 상황 묘사 → 「광주 ○○, ~할까요..?」 키워드 질문
4. 짧은 답 2~4줄
5. 원장 소개 「저는 산부인과 전문의 / 김샛별 대표원장입니다.」
6. 목차 표(번호 3개 + 4. 자주 묻는 질문)
7. 섹션 x3: 인용구(번호 소제목 + 서브 키워드) → 이미지 → 본문 → 「항목: 설명」 표 → 본문 → 이미지
8. 시술 언급 시 근거 한계 문장(「연구가 많지 않아 단정하기 어려워요」), 학회 정회원
9. 인용구 「오늘 이야기를 정리하면」 → 요약 4~6줄 → 이미지
10. 진료 요일 안내(야간진료) + 준비물 메모 안내
11. 인용구 「자주 묻는 질문」 → Q/A 3개
12. 같이 읽기 좋은 글 링크카드 2 → 유튜브 임베드 → 구분선
13. <네이버 예약 바로가기> 카드 → 전화 표 → <새봄의원 카카오톡> 카드 → 구분선
14. 「광주 ○○ 진료 안내」 진료시간 표 → 구분선 → <새봄의원 오시는 길> 지도
15. 의료광고 가이드라인 고지 이미지 2장

A 그룹 말투 규칙
- 문장을 모바일 기준 한 줄 16자 안팎으로 끊고 2~4줄마다 빈 줄
- 설명은 「~요」, 사실, 안내는 「~습니다/드립니다」, 이유는 「~거든요」로 붙임
- 독자 질문을 큰따옴표로 인용: 「"질염 약을 넣었는데 그대로예요."」
- 「~하지는 마세요」 금지 안내, 「~해 주셔도 돼요」 허용 안내
- 효과 단정 대신 「알려져 있어요」, 「개인마다 달라요」

## 4. 문제점

| 항목 | 판정 | 근거 |
|---|---|---|
| 이미지 비율 | 미흡 | A 그룹 363장 중 1:1은 19장(5%). 가로 4:3, 16:9가 섞임 → 앞으로 전부 1:1 |
| 키워드 반복 | 미흡 | A 그룹 「지역 + 핵심어」 글당 중앙값 8회, 최대 11회(리프팅, 스킨보톡스). 핵심어 단독 중앙 13회, 보톡스 28회 |
| 어색한 키워드 문장 | 미흡 | 「광주 질건조증일 수 있나요..?」, 「광주 산전검사 결과를 휴대폰에서」 |
| 첫 문단 답 | 보통 | 공감 도입 6~9줄 뒤에 답이 나옴. AI 브리핑 규칙(첫 2문장 답)과 불일치 |
| 병원명 혼용 | 보완 | 본문 새봄의원, 예약과 지도 새봄여성의원 |
| 「ㅎㅎ」 | 보완 | 의료진 1인칭 글에 21/33편. 신뢰도 측면에서 줄이는 것을 권장 |
| 태그 | 미적용 | 확인한 글 태그 0개 |
| 중복 주제 | 보완 | 산전검사 3편, 울쎄라 4편, 임신중절수술 5편, 레이저제모 5편 → 같은 키워드 자기잠식 가능성 |
